Project Overview : 

LegalEase is a web-based legal consultation platform. This repository contains the PHP backend and MySQL database integration used to support the application's features.

Features : 

User registration and login
Lawyer profile and information management
Lawyer availability and appointment management
API endpoints for frontend communication
Password reset with OTP verification
Stripe payment integration (server-side functionality, where implemented)

Technologies Used :

PHP
MySQL
WAMP Server
REST API

Frontend Repository: https://github.com/Uvindu7/LeagleEase_Backend
